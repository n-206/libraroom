# Libraroom

## Dokumentáció

Létrehoztunk egy daily-documentation nevű mappát amiben a napi dokumentáció látható, célunk vele, hogy a másik illetve a Lionsdale lássa a változtatásainkat. A cél, hogy leírjuk mit és miért változtattunk, adtunk hozzá a kódunkhoz. A hogyan része is belefér, bár célunk, hogy arra alapból a commit-ekből, pull request-ekből és a kódban található kommentekből jöjjön rá az olvasó.

## Kommunikáció

A kommunikáció egy külön erre a célra létrehozott discord csoportban zajlik magyar nyelven, de a git-en lévő kommunikáció, legalábbis a commit-ek, pull request-ek üzenete főképp angolul fog történni ugyanis az az ipari szabvány.
